# Sprites

Coloque aqui os 10 arquivos webp dos personagens:

- espadachim1 - sprites.webp
- espadachim2 - sprites.webp
- lutador1 - sprites.webp
- lutador2 - sprites.webp
- mago1 - sprites.webp
- mago2 - sprites.webp
- vampira1 - sprites.webp
- vampira2 - sprites.webp
- vampiro1 - sprites.webp
- vampiro2 - sprites.webp

Cada sprite sheet deve ser horizontal, com 5 linhas de animação:

**Sheet 1 (animações principais):**
- Linha 0: IDLE (8 frames)
- Linha 1: WALK (8 frames)
- Linha 2: RUN (8 frames)
- Linha 3: JUMP (6 frames)
- Linha 4: ATTACK (6 frames)

**Sheet 2 (animações secundárias):**
- Linha 0: ATTACK2 (6 frames)
- Linha 1: HIT (4 frames)
- Linha 2: DEATH (6 frames)
- Linha 3: SPECIAL (6 frames)
- Linha 4: DEFEND (4 frames)

Sem os sprites o jogo ainda roda — usa um retângulo colorido com a inicial do nome como fallback.
